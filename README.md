# Fresh Bake Website

A multi-page bakery website built with HTML, CSS, Bootstrap, and JavaScript, featuring landing sections, offers, about page, contact view, and sign-in/registration pages.

## Project Type & Contribution
- **Team Project:** Developed collaboratively as part of a team, with contributions to front-end pages, layout styling, and UI components.

## Tech Stack
- HTML5, CSS3, Bootstrap, JavaScript

## Project Structure
- `index.html`: Main landing page.
- `assets/pages/`: Subpages (About, Contact, Our Offer, Sign-Login).
- `assets/css/`, `assets/js/`, `assets/images/`, `assets/font/`: Styling, scripts, media, and fonts.
